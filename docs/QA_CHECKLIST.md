# 파이어 엠블렘 무쌍 한글 패치 QA 체크리스트

최종 통합 패치를 설치한 뒤 확인할 항목입니다.
번역 저장, 패치 출력, 실제 설치, 화면 확인은 서로 다른 단계입니다. 이 문서는 마지막 단계인 화면 확인용입니다.

## 0. 준비

이 게임은 **LayeredFS 로 적용할 수 없습니다.** romfs 를 덮으면 타이틀 화면에서 반드시 멈추며,
원본 파일을 그대로 얹어도 같은 증상입니다. 한글판 CIA 를 만들어 설치해야 합니다.

- 패처로 만든 `<이름>_KO.cia` 세 개(본편·업데이트·DLC)를 3DS 에 설치합니다.
- 업데이트를 설치해 쓰고 있다면 업데이트도 반드시 한글판으로 바꿉니다. 실행되는 프로그램이 그쪽입니다.
- 다시 설치할 때는 기존 한글 타이틀을 먼저 지웁니다. 세이브는 타이틀과 별도라 남습니다.
- SD 의 `luma/titles/000400000F70C100` 과 `0004000E0F70C100` 에 예전 LayeredFS 파일이 남아
  있으면 지웁니다. 남아 있으면 그것 때문에 멈춥니다.

## 1. 기술 확인 (먼저 봐야 할 것)

| # | 확인할 것 | 어디서 | 안 되면 |
|---|---|---|---|
| 1 | 한글이 깨지거나 엉뚱한 글자로 나오지 않는지 | 타이틀 → 데이터 선택 → 플레이스타일 선택 | 글리프 배정과 빌드 산출물이 같은 회차인지 확인 |
| 2 | 일본어 글리프가 망가지지 않았는지 | 미번역 구간(전투 음성 자막 등) | ARM 훅이 기존 조회 표를 건드렸는지 확인 |
| 3 | **버튼 아이콘**이 사라지지 않았는지 | 도움말의 「기본 액션」, 화면 아래 A/B 안내 | `{P*}` 제어코드 유실. `python tools/tl.py find <문구>`로 찾아 원문과 대조 |
| 3-1 | HOME 메뉴의 배너와 게임 이름이 한글인지 | 홈 화면에서 아이콘 선택 | CIA 에 배너·아이콘이 들어갔는지 확인 |
| 4 | **색 강조**가 원문과 같은 범위에 들어가는지 | 스테이터스 설명, 튜토리얼 | `{A*}`…`{R}` 배치 확인 |
| 5 | 대사창(400px)과 아래 화면(320px)에서 줄이 잘리지 않는지 | 스토리 대사, 메뉴, 무기 목록 | 줄바꿈 조정 |
| 6 | 순차 대사가 어긋나거나 빈 줄로 나오지 않는지 | 스토리 모드 전투 중 대사 | 레코드 길이 접두 계산 확인 |

## 2. 그래픽

| 대상 | 나오는 곳 |
|---|---|
| 제작사 로고 | 게임 시작 직후 |
| 주의 안내문 | 제작사 로고 다음 |
| 타이틀 로고, 하단 저작권 | 타이틀 화면 |
| 크레딧 하단 저작권 3줄 | 엔딩 크레딧 |
| 유대 레벨 상승 | 전투 후 유대 상승 연출 |
| DLC 배너 A | 추가 콘텐츠 메뉴 |

전투 알림(GAME OVER, STAGE CLEAR 등)과 일본어 DLC 배너 B는 원본을 유지하기로 했습니다. 한글이 아니어도 문제가 아닙니다.

## 3. 추가 콘텐츠(DLC)

DLC 는 별도 타이틀이라 DLC CIA 를 패처로 따로 만들어 설치해야 보입니다.

| 확인할 것 | 어디서 |
|---|---|
| c2·c3·c4 시나리오의 대사가 한글로 나오는지 | 추가 콘텐츠 각 시나리오 |
| 본편과 표기가 어긋나지 않는지 | 인물 이름, 클래스명 |

c1 과 c5 에는 순차 대사가 없어 손대지 않았습니다.

## 3-1. 아직 반영되지 않은 범위

화면에서 일본어가 보여도 아래는 예정된 상태입니다.

- **반각·혼합 인코딩 후보** 224종 1,792참조는 어느 언어 분기인지 판단이 남아 있습니다.
- 전투 알림(GAME OVER, STAGE CLEAR 등)과 일본어 DLC 배너 일부는 원본을 그대로 두기로 했습니다.

## 4. 표기 확인이 필요한 이름

용어집(`translation/glossary.json`)의 확정 표기를 우선합니다. 아래는 화면에서 보고 판단할 항목입니다.

| 원문 | 현재 표기 | 비고 |
|---|---|---|
| パオラ / カチュア / エスト | 파오라 / 카츄아 / 에스트 | DLC c3에서 임시로 쓰는 표기 |
| アンリ | 미확정 | 확정 표기로 보고하지 않음 |
