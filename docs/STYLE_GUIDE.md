# 한국어 번역 및 진행 보고 기준

2026-09-20 사용자 요청을 반영한 인수 기준.

## 문체

- 일본어 문장부호 유무를 그대로 따르지 않는다. 한국어 문장의 구조와 호흡에 맞춰 마침표, 쉼표, 물음표, 느낌표를 넣는다.
- 대사·설명문은 자연스러운 완결 문장으로 번역한다. 인물별 말투와 감정, 문맥을 유지한다.
- 메뉴명·버튼명·아이템명·짧은 상태 표시는 기능에 맞게 간결하게 쓴다. 모든 문자열 끝에 마침표를 일괄 추가하지 않는다.
- 줄바꿈은 실제 화면 폭과 문장 구조를 고려한다. 원문의 줄바꿈을 그대로 복사하거나 글자 수만 맞추려고 의미를 생략하지 않는다.
- 제어코드와 포맷 지정자를 보존한다. 강조 범위는 번역문에서 대응하는 단어를 감싸도록 배치한다.
- 인물명·고유명사는 `glossary.json`의 기존 확정 표기를 우선한다(사용자 재확인: 2026-09-20). 일반적인 표기나 다른 작품의 표기를 이유로 임의 변경하지 않는다. 용어집 파일 자체는 사용자 지시 없이 변경하지 않는다.
- 기존 번역도 신규 번역과 함께 검수한다. 이름·고유명사 표기는 보존하고, 오역·문장부호·띄어쓰기·직역투를 수정한다. 변경 전후와 원문을 검수 기록에 남긴다.
- 용어집에 없는 고유명사나 서로 충돌하는 기존 결정은 확인 대상으로 기록한다. 확정한 것으로 보고하지 않는다.

## 진행 보고

- 사용자 방침(2026-09-20): 장면마다 게임 진행을 기다리지 않는다. 전체 번역·패치 작성을 먼저 진행하고 실제 플레이 검수는 이후 일괄 수행한다. 화면 미검증은 기록하되 다음 번역 구간 진행의 선행 조건으로 삼지 않는다.
- 사용자 요청(2026-09-20): 배치가 끝나면 윈도우 완료 알림을 보낸다. 번역·검사·빌드가 끝난 뒤 `tools/notify_batch.ps1`을 Windows PowerShell 5.1로 실행하고 전송 결과를 기록한다. 실패나 적용 보류가 있으면 알림에도 정확히 표시한다. 화면에 알림이 보였다고 확인 없이 단정하지 않는다.

- 번역 작성, 자동 검사 통과, 패치 반영 검증, 게임 화면 확인을 구분한다.
- 번역 JSON에 값이 있다는 이유만으로 적용 완료 또는 UI 완료라고 보고하지 않는다.
- 수치는 집계 대상과 제외 기준을 함께 제시한다. 추출 캐시 기준 수치를 게임 전체 번역률이라고 부르지 않는다.
- 자동 검사 통과는 번역 품질, 블록 용량, 실행 성공을 보증하지 않는다.
- 미번역, 검사 실패, 용량 초과, 패치 누락을 별도 기록한다.
- 예비·테스트 문자열 제외는 기존 추출기의 추정이다. 화면에 나오는 문자열이 잘못 제외되지 않았는지 검토한다.
- 마침표 누락은 `python tools/audit_periods.py`, 물결표·대명사·띄어쓰기 등 문체 위반 후보는 `python tools/audit_style.py`로 훑는다.
- XL 밖의 순차 대사(`extract/dialogue_v2`)와 UTF-16 훈장은 별도 형식으로 추적한다. 기존 `meta.pkl` 개수만으로 전체 원문 수를 보고하지 않는다.
- 원문 종류뿐 아니라 모든 사용 위치의 추출·반영 여부도 검사한다. 다른 파일에서 같은 문구가 추출되었다고 특정 맵이나 대화의 반영이 보장되지는 않는다.
