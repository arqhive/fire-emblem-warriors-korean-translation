일본어로 남아 있던 그림 글씨를 한글로 바꾼 버전입니다. 텍스트 번역은 v0.2와 같습니다.

**원본 일본판 CIA(`000400000F70C100`, `0004000E0F70C100`, `0004008C0F70C100`)에 적용하는 전체 패치입니다.** 이전 버전으로 만든 한글판 CIA에는 덧씌울 수 없으니 일본판 원본으로 다시 만들어 설치하세요.

## 변경 사항

- 가이드 화면 그림 16장을 한글로 바꿨습니다. 미션 메뉴, 전투 준비, 승리·패배 조건, 맡기기 설정, 전투 결과, 지도, 유닛 정보, 요새 제압전, 록온, 장비 아이템 비교 등입니다.
- 추가 콘텐츠 메뉴의 「파이어 엠블렘 각성 추가 팩」 배너 두 종을 한글로 바꿨습니다.
- 주의 안내문, 타이틀 로고, 「유대 LEVEL UP!」 그림을 새로 그렸습니다.
- HOME 메뉴 전자 설명서의 전투 화면 그림 두 장과 amiibo 로고를 한글로 바꿨습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `CFMJ_KPatch_v0.2.1.zip` | 본인이 가진 일본판 CIA | 한글판 CIA를 만드는 패처와 사용자 설명서, 라이선스. 파이썬과 도구가 함께 들어 있습니다. |

이 게임은 LayeredFS로 적용할 수 없어 LayeredFS용 파일은 없습니다.

## 적용 방법

1. ZIP을 폴더째 풀고 일본판 CIA를 `패치하기.bat`에 끌어다 놓습니다. 여러 개를 한 번에 놓아도 되고, 본편·업데이트·DLC는 알아서 구분합니다.
2. 원본과 같은 폴더에 `<원래 이름>_KO.cia`가 생깁니다. 기존 한글판을 지운 뒤 FBI 등으로 3DS에 설치합니다. 세이브 데이터는 남습니다.
3. 암호화된 원본이면 `boot9.bin`과 `seeddb.bin`이 필요합니다. 패치 폴더나 Azahar·Citra의 `sysdata` 폴더에 있으면 자동으로 찾습니다.
4. **업데이트를 설치해 쓰고 있다면 업데이트도 반드시 한글판으로 바꿉니다.** 실제로 실행되는 프로그램이 업데이트 쪽입니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
