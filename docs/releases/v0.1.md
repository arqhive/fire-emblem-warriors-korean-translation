첫 배포입니다. 본편·업데이트·추가 콘텐츠의 텍스트와 대사, 훈장, 그림 글씨, HOME 메뉴 배너까지 한글로 바꿉니다. 가진 일본판 CIA를 한글판 CIA로 만드는 패처로 배포합니다.

**원본 일본판 CIA(`000400000F70C100`, `0004000E0F70C100`, `0004008C0F70C100`)에 적용하는 전체 패치입니다.**

## 변경 사항

- 캐시 원문 13,328개(메뉴, 무기·특성 설명, 전투 로그, 미션 조건, 히스토리 모드, 용어·인명)를 번역했습니다.
- 본편·업데이트의 순차 대사 9,950참조와 추가 콘텐츠의 순차 대사 3,014참조를 번역했습니다.
- 훈장 이름과 조건 88종(176참조)을 번역했습니다.
- 본문 폰트에 한글 1,151자를 넣었습니다. 일본어 글리프는 그대로 두고 비어 있는 칸을 씁니다.
- 제작사 로고, 주의 안내문, 타이틀 로고, 크레딧 저작권 등 그림 글씨 7종과 HOME 메뉴 배너·게임 이름을 한글화했습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `FEWarriors_KO_v0.1_Patcher.zip` | 본인이 가진 일본판 CIA | 한글판 CIA를 만드는 패처와 사용자 설명서, 라이선스. 파이썬과 도구가 함께 들어 있습니다. |

이 게임은 LayeredFS로 적용할 수 없어 LayeredFS용 파일은 없습니다. 본편과 업데이트가 같은 이름(`LINKDATA.bin`)의 서로 다른 파일을 쓰는데, LayeredFS는 본편 폴더의 파일을 두 곳에 모두 덮어씌우기 때문입니다.

## 적용 방법

1. ZIP을 폴더째 풀고 일본판 CIA를 `패치하기.bat`에 끌어다 놓습니다. 여러 개를 한 번에 놓아도 되고, 본편·업데이트·DLC는 알아서 구분합니다.
2. 원본과 같은 폴더에 `<원래 이름>_KO.cia`가 생깁니다. FBI 등으로 3DS에 설치합니다.
3. 암호화된 원본이면 `boot9.bin`과 `seeddb.bin`이 필요합니다(본편이 seed 암호화입니다). 패치 폴더나 Azahar·Citra의 `sysdata` 폴더에 있으면 자동으로 찾습니다.
4. **업데이트를 설치해 쓰고 있다면 업데이트도 반드시 한글판으로 바꿉니다.** 실제로 실행되는 프로그램이 업데이트 쪽입니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
