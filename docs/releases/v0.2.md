스토리 대사가 첫 줄 뒤로 제대로 나오지 않던 문제를 고친 버전입니다. 안내문의 조사·마침표·띄어쓰기도 다듬었습니다. 캐릭터 대사 번역은 v0.1과 같습니다.

**원본 일본판 CIA(`000400000F70C100`, `0004000E0F70C100`, `0004008C0F70C100`)에 적용하는 전체 패치입니다.** v0.1로 만든 한글판 CIA에는 덧씌울 수 없으니 일본판 원본으로 다시 만들어 설치하세요.

## 변경 사항

- 대화 장면에서 첫 대사 뒤로 같은 대사가 반복되거나 빈칸·「.」만 나오던 문제를 고쳤습니다. 대사 레코드의 길이 값을 게임이 읽는 방식(바이트 수 + 줄바꿈 수 + 1)대로 적습니다. 본편·업데이트·DLC의 모든 대화 장면에 해당합니다.
- 이름이 들어가는 안내문에서 받침에 따라 틀리던 조사를 고쳤습니다(113곳). 예: 「'신부'이 추가되었습니다」 → 「'신부' 의상이 추가되었습니다」.
- 캐릭터 무기 설명과 스킬 이름의 「강1」을 「강공격1」로 바꿨습니다(25곳).
- 확인 창·안내문에서 빠진 마침표를 채웠습니다(43곳). 예: 「스킵합니다 / 괜찮습니까?」, 「데이터를 지웁니다」.
- 「캐릭터 소개」 띄어쓰기를 통일하고, 끝에 잘못 붙은 마침표를 뺐습니다.
- 캐릭터 대사를 뺀 텍스트의 띄어쓰기를 정리했습니다. 예: 「평화의붕괴」 → 「평화의 붕괴」, 「진군개시」 → 「진군 개시」.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `FEWarriors_KO_v0.2_Patcher.zip` | 본인이 가진 일본판 CIA | 한글판 CIA를 만드는 패처와 사용자 설명서, 라이선스. 파이썬과 도구가 함께 들어 있습니다. |

이 게임은 LayeredFS로 적용할 수 없어 LayeredFS용 파일은 없습니다.

## 적용 방법

1. ZIP을 폴더째 풀고 일본판 CIA를 `패치하기.bat`에 끌어다 놓습니다. 여러 개를 한 번에 놓아도 되고, 본편·업데이트·DLC는 알아서 구분합니다.
2. 원본과 같은 폴더에 `<원래 이름>_KO.cia`가 생깁니다. 기존 한글판을 지운 뒤 FBI 등으로 3DS에 설치합니다. 세이브 데이터는 남습니다.
3. 암호화된 원본이면 `boot9.bin`과 `seeddb.bin`이 필요합니다(본편이 seed 암호화입니다). 패치 폴더나 Azahar·Citra의 `sysdata` 폴더에 있으면 자동으로 찾습니다.
4. **업데이트를 설치해 쓰고 있다면 업데이트도 반드시 한글판으로 바꿉니다.** 실제로 실행되는 프로그램이 업데이트 쪽입니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
