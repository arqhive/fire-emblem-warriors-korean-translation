3DS 데이터 관리 화면에서 추가 콘텐츠의 게임 이름이 영어로 나오던 것을 한글로 맞춘 버전입니다. 게임 안 번역과 그림은 v0.2.2와 같습니다.

**원본 일본판 CIA(`000400000F70C100`, `0004000E0F70C100`, `0004008C0F70C100`)에 적용하는 전체 패치입니다.** 이전 버전으로 만든 한글판 CIA에는 덧씌울 수 없으니 일본판 원본으로 다시 만들어 설치하세요. 이번에 바뀐 것은 추가 콘텐츠(DLC) CIA뿐입니다.

## 변경 사항

- 추가 콘텐츠의 게임 이름·제작사를 본편과 같은 「파이어 엠블렘 무쌍」·「코에이 테크모 게임스」로 바꿨습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `CFMJ_KPatch_v0.2.3.zip` | 본인이 가진 일본판 CIA | 한글판 CIA를 만드는 패처와 사용자 설명서, 라이선스. 파이썬과 도구가 함께 들어 있습니다. |

이 게임은 LayeredFS로 적용할 수 없어 LayeredFS용 파일은 없습니다.

## 적용 방법

1. ZIP을 폴더째 풀고 일본판 CIA를 `패치하기.bat`에 끌어다 놓습니다. 여러 개를 한 번에 놓아도 되고, 본편·업데이트·DLC는 알아서 구분합니다.
2. 원본과 같은 폴더에 `<원래 이름>_KO.cia`가 생깁니다. 기존 한글판을 지운 뒤 FBI 등으로 3DS에 설치합니다. 세이브 데이터는 남습니다.
3. 암호화된 원본이면 `boot9.bin`과 `seeddb.bin`이 필요합니다. 패치 폴더나 Azahar·Citra의 `sysdata` 폴더에 있으면 자동으로 찾습니다.
4. **업데이트를 설치해 쓰고 있다면 업데이트도 반드시 한글판으로 바꿉니다.** 실제로 실행되는 프로그램이 업데이트 쪽입니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
