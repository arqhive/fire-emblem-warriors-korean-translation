파이어 엠블렘 무쌍 (3DS) 한글 패치 v0.2
제작: arqhive

「ファイアーエムブレム無双」(닌텐도 3DS, 일본판) 비공식 한국어 팬 패치입니다.
본인이 가진 일본판 CIA로 한글판 CIA를 만들어 설치합니다.


[먼저 알아 둘 것]

이 게임은 Luma3DS의 게임 패치(LayeredFS)로는 한글화할 수 없습니다.
업데이트를 설치한 상태에서 romfs를 덮으면 타이틀 화면에서 반드시 멈춥니다.
본편과 업데이트가 같은 이름(LINKDATA.bin)의 서로 다른 파일을 쓰는데,
LayeredFS는 본편 폴더의 파일을 두 곳에 모두 덮어씌우기 때문입니다.
그래서 CIA를 다시 만드는 방식을 씁니다.


[준비물]

- 일본판 CIA. 아래 셋 중 가진 것을 준비합니다.
    본편            000400000F70C100
    업데이트 v6.9.0  0004000E0F70C100
    추가 콘텐츠      0004008C0F70C100
  북미판·유럽판(Fire Emblem Warriors)에는 적용할 수 없습니다.
  New 3DS 계열 전용 소프트입니다.

- CIA를 설치할 수 있는 CFW 3DS(FBI 등).

- 복호화용 boot9.bin 과 seeddb.bin.
  본편이 seed 암호화라 둘 다 필요합니다. 아래 위치에 있으면 자동으로 찾습니다.
    이 패치 폴더
    %APPDATA%\Azahar\sysdata\
    %APPDATA%\Citra\sysdata\
    사용자 폴더의 .3ds 폴더

- 임시 디스크 공간 약 10GB. 본편 romfs가 2.2GB라 작업 중에 공간을 많이 씁니다.
  작업 폴더는 패치 폴더 안의 work 이고, 끝나면 지웁니다.


[만드는 방법]

1. 일본판 CIA 파일을 「패치하기.bat」에 끌어다 놓습니다.
   여러 개를 한 번에 놓아도 됩니다. 타이틀 ID를 보고 본편·업데이트·DLC를 알아서 구분합니다.

2. 잠시 기다리면 원본과 같은 폴더에 <원래 이름>_KO.cia 가 생깁니다.
   원본 파일은 바뀌지 않습니다.

3. 만들어진 CIA를 3DS에 설치합니다.

- 업데이트를 설치해 쓰고 있다면 업데이트도 반드시 한글판으로 바꿔야 합니다.
  실제로 실행되는 프로그램이 업데이트 쪽이기 때문입니다.
- 업데이트와 추가 콘텐츠를 쓰지 않는다면 본편만 만들어 설치해도 됩니다.
- v0.1에서 올릴 때도 일본판 원본 CIA로 다시 만듭니다. 한글판 CIA에는 덧씌울 수 없습니다.
- 한글 패치를 다시 설치할 때는 기존 것을 먼저 지우는 쪽이 안전합니다.
  세이브 데이터는 타이틀과 별도로 저장되므로 지워도 남습니다.


[바뀌는 내용]

- 메뉴, 무기·특성 설명, 전투 로그, 미션 조건, 히스토리 모드, 용어와 인명
- 본편·업데이트의 대사와 추가 콘텐츠의 대사
- 훈장 이름과 조건
- 제작사 로고, 주의 안내문, 타이틀 로고, 크레딧 저작권 등 그림 글씨
- HOME 메뉴의 배너와 게임 이름

[알려진 문제]

- LayeredFS로는 적용할 수 없습니다. 위에 적은 대로 CIA를 다시 만들어야 합니다.
- 전투 알림(GAME OVER, STAGE CLEAR 등)은 원본 영어를 그대로 둡니다.
- 일본어로 된 추가 콘텐츠 배너 일부도 원본을 그대로 둡니다.
